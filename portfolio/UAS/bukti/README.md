# Berkas bukti UAS

Folder ini belum berisi evidence mahasiswa. Gunakan nama yang jelas, misalnya `D01-catatan-discovery.md` atau `U01-foto-prototipe.png`, kemudian tautkan dari halaman QMD dan register bukti. Contoh nama tersebut bukan klaim file telah tersedia.

Untuk setiap bukti, catat ID, tanggal, kontributor, mode nyata/simulasi, izin, dan penunjuk bagian penting. Lampiran teks dapat memakai Markdown; foto/dokumen pendukung sesuai kegiatan aktual. Jangan menciptakan kuitansi, testimoni, wawancara, atau hasil uji untuk melengkapi template.

Folder ini ditujukan hanya untuk bukti yang layak dipublikasikan. Bukti sensitif disimpan di tempat terbatas dengan akses assessor yang disepakati, bukan di repository publik. Menghapus tautan dari situs tidak membuat file Git menjadi privat.

Berkas di sini disertakan sebagai resource saat render; periksa kembali izin serta isi sebelum commit/publish. Portfolio utama tetap diedit pada file QMD di folder induk.
