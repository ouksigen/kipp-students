06 — Proposal Pendanaan dan Anggaran

Indeks paket · Citra, Alya, Bima. Uang/transaksi simulasi, tanpa kuitansi atau dana nyata.

Proposal ringkas

Plafon rencana Rp10 juta untuk discovery, belajar, prototipe, pilot, akses dan dukungan. Tim bersedia tahap awal Rp3 juta. Uji kepastian status dengan beban input sebagai penyeimbang. H6 lingkup/izin, H13 hasil, H16 laporan, H20 pengembalian. Jika gagal, laporkan dan hentikan perluasan.

Bentuk dukungan cerita: hibah latihan bersyarat pelaporan, bukan pinjaman/investasi berimbal hasil. Tidak ada janji keuntungan atau akses identitas pelanggan. Rp7 juta tahap berikutnya tidak disetujui/dicairkan.

Baris Pembicara Ujaran ilustratif
L01 Maya / panel Mengapa Rp10 juta sebelum tahu papan dipakai?
L02 Alya Itu batas, bukan minimum. Bukti apa untuk menyetujui uji kecil?
L03 Maya Biaya jelas, staf bersedia, data awal. Saya setujui tahap Rp3 juta.
L04 Bima Kami tunda aplikasi dan iklan; sepuluh tugas sintetis tidak membuktikan omzet.

L06 Maya Ya, maksimal H20. Jangan otomatis dibelanjakan.

Adaptasi: permintaan penuh berubah menjadi tahap belajar. Batas diterima; bukan kontrak hibah nyata.
