Cara bekerja dengan template

  1. Isi identitas, pilih kasus, dan sepakati peran. Edit file QMD, bukan HTML hasil render.
  2. Catat bukti sambil bekerja: ID unik, tanggal, kontributor, nyata/simulasi, tautan, dan penunjuk baris/timestamp. Satu bukti boleh dirujuk lintas halaman tanpa digandakan.
  3. Untuk tiap sesi komunikasi, gunakan tabel laporan di halaman terkait. Tambahkan sesi bila satu sesi belum mencakup kontribusi semua anggota.
  4. Simpan berkas pendukung yang layak dipublikasikan di bukti/, lalu tautkan secara relatif dari halaman yang relevan. Baca panduan bukti. Dokumen sensitif tetap di penyimpanan terbatas yang disepakati dengan assessor.
  5. Ubah status menjadi Draft, Siap dinilai, Perlu revisi, atau Tercapai sesuai proses. Hapus petunjuk yang tidak diperlukan setelah isi lengkap.
